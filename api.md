# План API

## Назначение

API предназначен для работы с данными о футболистах.

## Методы

### GET /players
Получение списка футболистов.

### GET /players/{id}
Получение информации о конкретном футболисте.

### POST /players
Добавление нового футболиста.

### PUT /players/{id}
Изменение данных футболиста.

### DELETE /players/{id}
Удаление футболиста.

## Данные футболиста

- id
- name
- team
- position
- age
- nationality

API является учебным планом и не представляет собой работающий сервер.
