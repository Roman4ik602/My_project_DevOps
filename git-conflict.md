# Git Conflict

## Причина конфликта

Конфликт возник при объединении ветки `main` с веткой `fix/conflict-demo`.

В обеих ветках были изменены одни и те же строки файла `README.md`.

## Разрешение конфликта

Git обнаружил конфликт и пометил конфликтующий участок файла.

Конфликт был разрешён вручную. После этого были удалены специальные маркеры конфликта и оставлен итоговый вариант текста.

## Результат

После разрешения конфликта был создан коммит:

`Обновил README после конфликта`

Изменения были отправлены на GitHub.
Конфликт успешно разрешён.
